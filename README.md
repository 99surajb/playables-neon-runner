# Neon Runner 极速光轮

A high-speed neon-themed endless runner built for YouTube Playables.

## Features
- **Vibrant Neon Aesthetics:** Procedural glowing visuals and perspective grid.
- **Dynamic Difficulty:** Speed and obstacle frequency increase over time.
- **Web Audio API:** Real-time synthesized sound effects.
- **YouTube Playables SDK:** Fully integrated for game state, health checks, and cloud storage.
- **Responsive Design:** Optimized for both mobile and desktop browsers.

## Controls
- **Touch/Mouse:** Tap Left/Right side of the screen to switch lanes.
- **Keyboard:** Use Left/Right Arrow keys.

## Technical Details
- **Engine:** Vanilla JavaScript + HTML5 Canvas.
- **Size:** ~15KB (Single file, no external assets).
- **Performance:** Constant 60FPS on most devices.
